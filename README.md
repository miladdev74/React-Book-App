<h3>📚 Book App</h3>
<h4>A modern and responsive book browsing application built with React and Vite.</h4>

<h4>This project allows users to explore a collection of books, search for specific titles and add their favorite books to a dedicated favorites section.</h4


<h3>✨ Features </h3>

<h4>🔍 Search for books by title</h4>
<h4>📚 Browse available book titles</h4>
<h4>❤️ Add books to a favorites list</h4>
<h4>🎨 Clean and organized layout</h4>
<h4>⚡ Fast development experience with Vite</h4>


<h3>🛠️ Technologies Used</h3>

<h4>React</h4>
<h4>Vite</h4>
<h4>JavaScript</h4>
<h4>HTML5</h4>
<h4>CSS3</h4>

<h3>🚀 Getting Started</h3>                                                                                                  

<h4>1. Clone the repository</h4>
 git clone https://github.com/miladdev74/React-Book-App

<h4>2. Navigate to the project directory</h4>
cd-book-app

<h4>3. Install dependencies</h4>

npm install

<h4>4. Start the development server</h4>
npm run dev
